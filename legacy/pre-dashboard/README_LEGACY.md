# Pre-Dashboard Legacy Snapshot

This folder preserves the WeatherBot source before the dashboard and SQLite layer were added.
It is historical source only. Do not use it for current startup, configuration, trading, or validation instructions; use the repository root `README.md` instead.

It intentionally excludes local-only files:

- `.venv/`
- `data/`
- `config.json`
- `__pycache__/`

Use `config.example.json` as a template if you need to run this legacy version locally.
