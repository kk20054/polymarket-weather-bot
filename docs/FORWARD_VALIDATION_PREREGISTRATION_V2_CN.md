# WeatherBot 前瞻验证预注册 v2

> 状态：**冻结**。协议自 `2026-07-26T17:30:00Z` 起生效。v2 是本路线最后一个版本；若再发现结构性缺陷，只能作废并终止该路线，不得建立 v3。

## 1. v1 作废依据

同一批权威结算且严格匹配的 324 个天气事件、3564 个市场桶中：

| 指标 | 实证结果 |
|---|---:|
| 收盘前 15 分钟 ask 落在 `<0.05` 或 `>0.95` | 88.5% |
| 赢家桶端点代理 ask 中位数 | 0.999 |
| 输家桶端点代理 ask 中位数 | 0.001 |
| 严格可执行 ask 的“收盘前 ask − 决策 ask”标准差 | 0.2169 |
| 单边端点代理的 P&L 量级标准差 | 0.2761 |
| v1 错用的普通 6 小时 ask 变动标准差 | 0.1029 |

两端占比超过预先规定的 70% 判定线。收盘前 15 分钟报价已接近结算结果，所以 v1 的 CLV 实际是单位 P&L；以 `sd=0.1029` 推导的 `N=73` 无效。

## 2. 主假设与固定队列

唯一主假设：

> 在决策时 YES ask 为 `0.20 <= ask < 0.40`、模型优势 `edge >= 0.08`、策略为 `core_modal_v1`、预测算法为 `polywx_aligned_deb_v1` 的首次模型侧候选中，平均无结果锚点 CLV 显著大于 0。

固定规则：

- 每个 `protocol_id + token_id + target_date` 只取首次候选，入场条件和报价不可被后续 UPSERT 改写。
- 主队列不要求 `paper_allowed=true`；`paper_allowed` 是固定分层，不是统计准入条件。
- 这只扩大统计观测队列，不改变 spread、depth、order minimum、stale book、truth 成熟度或任何交易风控。
- 行情、预测峰值和时间信息必须在决策时已经可得；最终 truth 不参与入组或锚点计算。

## 3. CLV 定义与锚点

主指标：

`CLV = A 锚点最后可得 YES ask − 决策时 YES ask`

A 锚点：

`min(决策时刻 + 6 小时, 当时预测峰值时刻 − 1 小时)`

报价契约：

- 只接受 A 锚点之前 15 分钟内最后一条 `0 < best_ask < 1` 的真实 ask。
- 空 ask side、`best_ask=0`、抓取失败或锚点后的报价都不能替代。
- 无有效报价的候选保留为“锚点缺失”，但不计入达到 N 的有效 CLV 样本。

四个候选锚点按预先写死的规则比较：在可用率至少 70% 的锚点中选标准差最小者。A 的可用率为 76.2%、标准差为 0.2216，因此被唯一选中；检测平均 `+3pp` CLV 需 `N=338`。

A 不读取最终结果，因而没有字段层面的结果泄漏。历史事后核对中，A 严格早于最终实测峰值的比例为 61.0%，并非 100%；这个数字只作安全审计，不用于剔除样本或移动锚点。

## 4. 样本量、速率与日期

| 口径 | 原始候选速率 | 乘以 76.2% 锚点可用率 | 达到 N=338 | 预计日期 |
|---|---:|---:|---:|---|
| 模型侧候选（主队列） | 28.17/日 | 21.47 个有效锚点/日 | 16 天 | 2026-08-12 |
| `paper_allowed=true` | 0.50/日 | 0.38 个有效锚点/日 | 887 天 | 2028-12-30 |

模型侧主队列是必要选择：若要求全部交易闸门通过，预计远超 120 天。v2 同时记录 `paper_allowed=true/false`，从而分离“模型是否有信息”与“盘口是否可成交”。

2026-07-28T15:30:00Z 的 48 小时检查点只更新观测速率、分布与阻塞计数，不修改本协议、样本量或预计日期。

## 5. 固定分层

以下分层全部预先固定；其他任何切片只能标为探索性：

- H-A：`edge >= 0.15`。
- H-B：`0.08 <= edge < 0.15`。
- ask：`0.20–0.30`、`0.30–0.40`。
- lead：`D+0`、`D+1`；其他 lead 如实单列。
- 可执行性：`paper_allowed=true`、`paper_allowed=false`。

H-A 与 H-B 是互斥竞争假设。二者均记录 CLV、Brier、命中率和 paper P&L；中途结果不得改变 edge 或 ask 定义。

## 6. 指标与停止规则

| 层级 | 指标 | 固定口径 |
|---|---|---|
| 主要指标 | 平均 A 锚点 CLV | 单侧 alpha=5%，power=80% |
| 目标效应 | +3 个百分点 | 历史标准差 0.2216 |
| 目标样本 | 338 个有效锚点 | 入组但锚点缺失的不计入 N |
| 次要指标 | Brier / log loss | 同一冻结队列，模型与决策时市场概率对照 |
| 次要指标 | paper P&L / ROI | 不能替代主要指标 |
| 诊断指标 | 可执行率与阻塞原因 | 不得用于放宽风控 |

停止规则：

1. 第 338 个有效 A 锚点报价落库后立即冻结队列并评估，不得延长。
2. 主要指标要求平均 CLV 的单侧 95% 置信下界大于 0，才支持继续投入。
3. 若主假设不成立，事后城市、温度桶或新分箱不能推翻结论。
4. Brier 优于市场只能证明概率质量，不能单独证明可赚钱。
5. `LIVE_TRADING` 保持关闭；本协议不授权实盘。

## 7. 不可变更声明

v2 的主假设、队列、锚点、样本量、分层和停止规则从本文件冻结后永久不再修改。若 v2 再被证明存在结构性缺陷，本路线终止；不得以任何理由建立 v3、追加样本或更换主指标。
