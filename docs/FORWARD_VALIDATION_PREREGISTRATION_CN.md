# WeatherBot 前瞻验证预注册 v1

> 状态：冻结。协议从 `2026-07-26T15:30:00Z` 起生效。v1 达到停止规则前不得修改；后续想法只能建立新版本，并标为探索性，不能回写 v1。

## 主假设

在决策时 YES ask 为 `0.20 <= ask < 0.40`、模型优势 `edge >= 0.08`、策略为 `core_modal_v1`、预测算法为 `polywx_aligned_deb_v1` 且通过既有 `paper_allowed` 风险闸门的 V3 冷启动候选中，平均收盘价优势（CLV）显著大于 0。

这里的 CLV 定义为：

`收盘前 15 分钟内最后可得 YES ask - 决策时 YES ask`

每个 `token_id + target_date` 只取首次符合条件的候选。行情、预测和观测必须是决策时已经可得的数据；结算后信息不得进入候选选择。

## 指标与样本量

| 层级 | 指标 | 预注册口径 |
|---|---|---|
| 主要指标 | 平均 CLV | 单侧检验，alpha=5%，power=80% |
| 目标效应 | +3 个百分点 | 历史 ask 变动标准差 `0.1029` |
| 目标样本 | 73 | 达到 73 后立即评估 |
| 预计评估日 | 2026-08-03 | 按历史 20–40¢ 候选速率 9.33/日估算 |
| 次要指标 | 多分类/二元 Brier、log loss | 同一预注册队列与市场价格对照 |
| 次要指标 | paper P&L / ROI | 持有至退出或结算，不能替代主要指标 |
| 诊断指标 | 保守 CLV | 收盘前最后 bid - 决策 ask；只作诊断 |

预计日期不是延长样本的理由。若运行故障导致日期到达但样本未满，继续到第 73 个有效样本；若先达到 73，则立即停止并评估，不因结果不理想而追加样本。

## 固定分层

只预注册以下分层，其他切片一律标为探索性：

- ask：`<0.05`、`0.05–0.10`、`0.10–0.20`、`0.20–0.40`、`>0.40`。
- lead：`D+0`、`D+1`。
- H-A：`edge >= 0.15`，代表“模型与市场分歧越大越有价值”。
- H-B：`0.08 <= edge < 0.15`，代表“模型接近市场时反而更可靠”。

H-A 与 H-B 是互斥的竞争性解释，两者都持续记录 CLV、Brier、命中率和 P&L。v1 不因中途结果修改 edge、ask 或风控阈值，最终由第 73 个样本后的数据裁决。

## 停止与决策规则

1. 第 73 个有效主队列样本完成收盘前报价后，冻结数据并评估。
2. 主要指标要求平均 CLV 的单侧 95% 置信下界大于 0，才支持继续投入。
3. 若主要指标不成立，P&L 或某个事后城市/温度桶切片不能推翻该结论。
4. Brier 优于市场只能证明概率质量改善，不能单独证明可赚钱。
5. `LIVE_TRADING` 在本协议期间保持关闭；本协议不授权实盘。
